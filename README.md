# Deletionpedia

Deletionpedia *was* an anti-deletionist inclusionist project to rescue articles that are about to be deleted on Wikipedia.

[everybodywiki](https://en.everybodywiki.com) is created by someone else but looks like a good alternative.

Idea: build it on nostr instead of mediawiki https://github.com/guaka/deletionpedia/issues/36


## antidelete.py

This bot is based on [pywikibot](https://www.mediawiki.org/wiki/Manual:Pywikibot). It may be an older version and YMMV.
